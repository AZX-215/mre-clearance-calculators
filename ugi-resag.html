How it works

1. Confirm the selected conductor has a chart value for the actual span.
2. Identify the lower secondary attachment height between the two poles.
3. Subtract the chart measurement from that lower attachment height.
4. The result is the maximum height to which the conductor can be resagged for that pole pair.
This calculator reproduces the values provided in the supplied UGI sag chart. It does not create values for span lengths that are not explicitly listed in that chart.
